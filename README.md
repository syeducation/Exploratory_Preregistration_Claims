High Levels of Reporting of Exploratory Research in Registered Reports and Preregistered Articles

Study Repository: Manuscript, Supplement, Preregistration, Data, Code, Materials, Reproducibility 

Background

Preregistration and Registered Reports restrict exploratory research, right? So some people say, but we have limited data related to this claim, and the available data suggest the opposite is true. The purpose of this project was to evaluate this claim. This project was submitted to COS’s Lifecycle Journal using a two-stage process similar to Registered Reports.

Reproducibility

To reproduce the cleaning, reliability, and/or analysis, download this full repo and open the “Exploratory_Preregistration_Claims.Rproj” R Project File in the root directory, https://osf.io/4vbtq. From there, open the code file of interest and—with luck—everything will run.
